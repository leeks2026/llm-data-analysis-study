# 1. 프로젝트 제목
비가 오는 날, 서울 지하철 이용은 어떻게 달라지는가? 강수 강도·시간대별 분석

# 2. 프로젝트 배경 및 목적
비가 오면 걷거나 자전거를 이용하기 어려워져 지하철 이용이 늘 수 있다고 예상할 수 있다. 
하지만 이용량이 모든 시간대와 요일에 같은 방식으로 변하는지는 확인이 필요하다. 
출퇴근 이동은 유지되더라도, 비가 많이 오는 날에는 낮 시간대나 주말 외출이 줄어 들 수 있다.
본 프로젝트는 서울교통공사 관할 역의 일별·시간대별 승하차 인원과 서울의 일별 강수량을 결합해, 
강수와 지하철 이용량의 관계가 강수 강도·시간대·요일에 따라 달라지는지 분석한다. 
결과는 관찰된 관계로 해석하며, 강수가 이용량 변화를 직접 일으켰다고 단정하지 않는다.

# 3. 핵심 분석 질문
1. 비가 온 날과 오지 않은 날의 지하철 이용량은 어떻게 다른가?
2. 강수량이 많아질수록 지하철 이용량도 계속 증가하는가, 아니면 강수 강도에 따라 양상이 달라지는가?
3. 강수량과 지하철 이용량의 관계는 시간대와 평일·주말에 따라 달라지는가?

# 4. 데이터 확보 계획
| 데이터 | 출처 | 주요 항목 | 활용 목적 |
|---|---|---|---|
| 역별 일별·시간대별 승하차 인원 | [서울 열린데이터광장](https://data.seoul.go.kr/dataList/OA-12921/S/1/datasetView.do) | 날짜, 역명, 시간대별 승차·하차 인원 | 역·날짜·시간대별 지하철 이용량 |
| 일별 기상 관측 | [기상청 ASOS](https://data.kma.go.kr/data/grnd/selectAsosRltmList.do?pgmNo=36&tabNo=2) | 날짜, 일강수량, 평균기온 | 날짜별 강수 여부와 강수량 |


- 분석 기간은 2023년 1월부터 2025년 12월까지로 설정한다.
- 서울 열린데이터광장에는 2023·2024·2025년의 역별 승하차 자료가 연도별 CSV로 제공된다. 공개된 세 파일의 용량은 각각 약 24MB다. 이 자료는 서울교통공사 관할 구간에 한정된다.
- 기상청에서 같은 기간의 서울 ASOS 일자료를 내려받는다. 기상청 안내에 따르면 ASOS 자료에는 강수와 기온 등이 포함되며, 일자료는 최대 10년 범위로 조회할 수 있다.
- 지하철 자료 세 파일을 연도별로 합친 뒤, 날짜를 기준으로 기상자료와 결합한다.

# 5. 예상 데이터 구조
분석용 자료는 역 × 날짜 × 시간대별 승하차 정보를 한 행으로 정리한다.

| 변수 | 설명 | 생성 또는 출처 |
|---|---|---|
| `date` | 이용 날짜 | 지하철 자료 |
| `station` | 역명 | 지하철 자료 |
| `time_band` | 시간대 구분 | 원자료의 시간대 항목 |
| `boardings` | 승차 인원 | 지하철 자료 |
| `alightings` | 하차 인원 | 지하철 자료 |
| `precipitation_mm` | 일강수량(mm) | 기상청 자료 |
| `avg_temp_c` | 일평균 기온(℃) | 기상청 자료 |
| `is_rainy` | 강수 여부 | 강수량이 0보다 큰 날로 생성 |
| `weekday` | 요일 | 날짜에서 생성 |
| `is_weekend` | 주말 여부 | 날짜에서 생성 |
| `month`, `year` | 월, 연도 | 날짜에서 생성 |


기상자료는 날짜별 약 1,096행이 예상된다. 지하철 자료의 최종 행 수는 역 수와 시간대별 원자료 구조를 확인한 뒤 기록한다. 강수량이 비어 있는 경우에는 무강수로 처리하지 않고 결측값인지 확인한다.

# 6. 예상 분석 방법
데이터 정리 및 품질 확인
- 연도별 지하철 파일을 합치고 날짜 형식과 역명을 통일한다.
- 역·날짜·시간대별 중복 및 결측 여부를 확인한다.
- 원자료의 시간대 구분을 확인한 뒤, 가능하면 출퇴근 시간대와 그 외 시간대로 묶는다. 구분이 적절하지 않으면 원래 시간대 구분을 유지한다.
- 강수일은 일강수량이 0보다 큰 날로 구분하고, 강수량은 연속형 변수로도 사용한다.

탐색적 분석
- 강수일과 무강수일의 평균 승차 인원을 역·시간대별로 비교한다.
- 강수량과 승차 인원의 관계를 산점도와 요약 통계로 살펴본다.
- 평일·주말 및 시간대별로 강수와 이용량의 관계가 달라지는지 비교한다.

통계 분석
분석 단위는 역 × 날짜 × 시간대로 둔다. 회귀분석에서는 역별 기본 이용량의 차이를 고려하고, 요일·월·연도도 함께 통제한다. 강수량과 시간대, 강수량과 평일·주말의 상호작용을 포함해 관계의 차이를 살펴본다.
강수 강도별 비교는 각 범주에 충분한 관측일이 있는지 확인한 뒤 시행한다. 같은 날짜의 강수량이 여러 역에 적용되므로, 통계적 불확실성을 계산할 때 날짜별 반복 관측을 고려한다. 결과는 인과관계가 아니라 관찰된 연관성으로 해석한다.

# 7. 생성형 AI 활용 계획
생성형 AI를 CSV 전처리, 날짜 결합, 시각화, 회귀분석 코드의 초안 작성에 활용한다. 다음 항목은 실제 자료와 실행 결과를 바탕으로 직접 확인한다.
- 세 연도 파일의 날짜 범위와 열 이름, 시간대 정의
- 기상자료와 지하철 자료의 날짜 결합 결과 및 누락·중복 여부
- 강수량 결측값과 무강수값의 구분
- 시간대 집계와 통계모형이 분석 계획에 맞게 적용됐는지
- 결과 해석에 근거가 부족한 인과 주장이 포함됐는지
